JUST US — A Romantic Surprise Website
=====================================

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted "for_my_love_surprise" folder in VS Code.
3. Open index.html in your browser, or install VS Code's Live Server extension.
4. Right-click index.html → Open with Live Server.

PAGES
- index.html    : Welcome / home page
- story.html    : Your relationship timeline
- reasons.html  : Reasons why she is special
- letter.html   : A romantic letter
- surprise.html : Clickable final surprise

CUSTOMIZE BEFORE SHOWING HER
- Open the HTML files and edit the visible Bengali/English text.
- The relationship dates and names are already filled in from the details provided earlier. Please verify them before sharing.
- You can add your own photos by replacing the illustrated portrait area in index.html with an <img> tag and styling it in style.css.
- For a more personal surprise, add your own couple photos and a message in your own words.

NOTES
- Internet is needed for Google Fonts. The site itself works locally without a backend.
- No external music is included. You can add a song you own or have permission to use if you want background music.
